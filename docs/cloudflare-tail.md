# Cloudflare Tail (retired)

Factorize no longer installs or delivers Cloudflare Tail events. The old
receive endpoints return HTTP 410. Existing Event occurrence history remains
available. The old installation instructions are preserved in Git history,
not in the active documentation.

The separate **Cloudflare REST API** integration is for authorized API calls;
it does not replace Tail event ingestion. See
[Integration access](https://docs.factorize.sh/integrations/oauth).
