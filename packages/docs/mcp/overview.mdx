---
title: Connect your agent
description: Authorize an MCP client to discover Events and subscribe to occurrences.
---

Use Factorize's remote Streamable HTTP endpoint:

```text
https://app.factorize.sh/mcp
```

Configure the endpoint in your MCP client and complete its OAuth flow. Authorize
`triggers:read` to discover Events and read occurrences. Authorize
`triggers:write` to create Events and Triggers, configure sources, and fire a
manual Trigger. Other scopes apply only to their corresponding integrations or
application operations.

Ask your client to call `list_events` and `list_triggers`. An empty list is a
successful connection to a workspace without configured Events or Triggers.

## Event subscriptions

MCP clients can subscribe to an Event occurrence resource. When a Trigger
publishes a validated occurrence, the server sends a resource-updated
notification. Read the resource to obtain the durable occurrence data. A client
that reconnects can use `list_event_occurrences` or the corresponding REST
endpoint to recover stored occurrences.

## Built-in workflow skills

Factorize publishes built-in MCP Skills with workflow guidance. Use
`skills/list` to discover the catalog and `skills/get` to get the
`manage-triggers` manifest. Read its resource for instructions on managing
Events and Triggers.
