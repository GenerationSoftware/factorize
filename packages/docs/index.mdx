---
title: Factorize with your agent
description: Connect your agent, create a job, run it, inspect the result, and automate it.
---

Factorize hosts your job configuration, trigger routing, queue, run history, and MCP endpoint. Your conversational agent controls Factorize through MCP; the execution agent runs each job using an execution account you connect.

Start at [app.factorize.sh](https://app.factorize.sh). Connect your agent to `https://app.factorize.sh/mcp`, create a manual job, inspect its result, then add a schedule or provider trigger.

You supply an execution account (exe.dev or Amp), repository access, model access, and any Linear, GitHub or ClickUp accounts needed by the job. Factorize hosts the application; it does not grant your execution agent access to those accounts. Add execution integrations in the browser before asking your agent to create a job. [Self-hosting](/self-hosting/deployment) is optional.
