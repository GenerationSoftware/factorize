---
title: Factorize with your agent
description: Connect your agent, define Events, and publish durable occurrences through Triggers.
---

Factorize stores versioned Event definitions, input Triggers, and durable Event
occurrences. MCP subscribers receive notifications when an occurrence is
available and can read it later. Skills remain standalone instruction documents.

Start at [app.factorize.sh](https://app.factorize.sh), connect an MCP client to
`https://app.factorize.sh/mcp`, create an Event and attach one or more Triggers.
