title: Factorize with your agent
description: Connect your agent, create a trigger, run it, inspect the result, and automate it.
---

Factorize hosts your trigger configuration, event routing, queue, run history, and MCP endpoint. Your external agent and hosted Pi use the same MCP tools and team skills. Pi runs inside Factorize with PostgreSQL persistence and an optional remote workspace.

Start at [app.factorize.sh](https://app.factorize.sh). Connect your agent to `https://app.factorize.sh/mcp`, create a manual trigger, inspect its result, then add a schedule or provider event.

Configure an OpenAI-compatible provider URL and optional key in Integrations,
then choose a model and permissions in Team settings. Add an exe.dev or Fly
workspace only when a task requires a VM. Each user receives a personal team;
skills, Triggers, runs and integrations live directly in that team.
[Self-hosting](/self-hosting/deployment) is optional.
