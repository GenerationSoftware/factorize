## Connect an MCP client

Connect to `https://app.factorize.sh/mcp` using the [MCP setup guide](/mcp/overview).
Authorize `triggers:read` to discover Events and occurrences, and `triggers:write`
to create or change Events and Triggers.

## Create and publish an Event

An Event defines the payload shape. A Trigger belongs to one Event and watches
an input source. Multiple Triggers may publish to the same Event.

Use the `create_event` MCP tool or the REST API to create an Event named `review.requested`
with a JSON object payload schema. Then call `create_trigger` to add an enabled Trigger attached to it.
For a simple local check, create a manual Trigger and fire it with a stable
idempotency key and a JSON payload accepted by the Event schema.

```json
{
  "eventId": "EVENT_ID",
  "name": "manual-review",
  "sources": [{ "kind": "manual", "config": {} }]
}
```

## Subscribe, fire, and read

Call `list_events` or `get_event` to find the Event ID. Subscribe to
`factorize://events/{eventId}/occurrences` before firing the Trigger.

Call `fire_trigger` with `triggerId`, `idempotencyKey`, and `data`. The response
includes the durable occurrence ID. Reusing the same idempotency key returns
that ID and reports a duplicate.

Read the resource after the MCP update notification. After reconnecting, use
`list_event_occurrences` to recover occurrences that arrived while disconnected.

The same data is available from `GET /api/v1/events/{eventId}/occurrences`.
