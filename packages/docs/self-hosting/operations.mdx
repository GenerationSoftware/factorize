---
title: Operations
description: Maintain the Factorize Worker, database, and static application.
---

Use the [deployment guide](/self-hosting/deployment) and the repository's
package-migration runbook for release and rollback procedures. Keep API
migrations, generated OpenAPI, API client output, and static frontend aligned.

The API Worker processes schedules and inbound provider webhooks. Monitor Worker
errors, database connectivity, and provider delivery outcomes. Event occurrences
are durable database records; MCP notifications prompt clients to read them and
are not the persistence layer.

Before a release, run the repository's documented local validation against an
isolated database. Never point validation at production or a shared database.
