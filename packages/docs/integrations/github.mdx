---
title: GitHub Triggers
description: Configure GitHub webhook inputs that publish Event occurrences.
---

Connect a GitHub installation, then attach a GitHub source Trigger to an Event.
Choose the installation, repository, webhook event, action, and optional
conditions in the Trigger configuration. Factorize verifies webhook signatures
and deduplicates provider delivery IDs before validating and storing the Event
occurrence.

Inspect safe delivery outcomes with `list_trigger_webhook_activity` and
`list_webhook_deliveries`. Use [Event payload and condition guidance](/integrations/events)
for payload validation and [troubleshooting](/troubleshooting/events) for
rejected or missing deliveries.
