---
title: Integration access
description: Connect external services used by Trigger inputs and MCP clients.
---

Integrations hold server-side credentials used to validate provider webhooks or
make authorized API requests. Select only the integrations needed for your
Triggers or MCP connection. Credentials are encrypted and never returned by
Factorize APIs.

Bearer API, GitHub, Linear, ClickUp, X, Fly.io, exe.dev, Amp, and Cloudflare Tail
integrations have distinct setup flows. Cloudflare Tail is an inbound webhook
signing integration. Use the browser's Integrations page to connect or revoke
credentials and to choose which MCP clients may access them.

Events and Trigger source definitions store references and configuration, not
credentials. Disconnecting an integration can prevent its future input
processing; it does not rewrite already stored Event occurrences.
