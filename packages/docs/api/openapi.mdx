[Download openapi.yaml](/openapi.yaml). Clients can use this exact file to generate SDKs or inspect request and response schemas.

The definition is generated from the capability route declarations assembled by `packages/api/src/api-contract.ts`. For an API change, update the owning capability’s `api/rest.ts` declaration (method, path, scope, validation, handler, and documentation), then run:

```bash
npm run generate:openapi
```

Commit `packages/docs/openapi.yaml` with the change. CI regenerates it and rejects a diff; parsed contract tests also require exact method/path equality with the executable catalog. Shared schemas and general API metadata live beside the catalog in `trigger-schemas.ts`, `trace-replay-schemas.ts`, and `api-document.json`.

Run `npm run validate --workspace=factorize-docs` to verify the generated artifact, parsed operation contract, and Mintlify configuration before publishing.
