---
title: Manual job invocation permissions
description: Authorize jobs to start other jobs with run-scoped credentials.
---

Manual invocation permissions are separate from lifecycle subscriptions. Configure the allowed destination jobs in a source job's editor. The public API can read them with `GET /api/v1/jobs/{jobId}/invocation-permissions` and replace them with an owner-session-only `PUT` containing `{"destinationJobIds":["..."]}`. Destinations must exist in the same tenant. Deleting either job removes its permission edges. Revocation takes effect on the next invocation request.

Permissions are tenant-local. A destination may be in another project in the same tenant; graph consumers should render that as a cross-project edge. Existing lifecycle, edited, idle, schedule, and webhook triggers remain independent and do not grant manual invocation.

While an agent or code job is executing on an exe.dev VM, Factorize provides `FACTORIZE_API_URL` and `FACTORIZE_RUN_TOKEN` to its process environment. The token is bound to the actual source job and run, expires after 24 hours, and stops authorizing requests when that run is no longer active. Do not pass a source job or run ID: the service derives both from the credential.

Use the normal manual invocation endpoint, which is also the `invoke_job` MCP tool:

```sh
curl --fail-with-body -X POST "$FACTORIZE_API_URL/jobs/DESTINATION_JOB_ID/invocations" \
  -H "Authorization: Bearer $FACTORIZE_RUN_TOKEN" \
  -H 'Content-Type: application/json' \
  --data '{"prompt":"Run the authorized follow-up","data":{"key":"value"},"idempotencyKey":"source-run-step-1"}'
```

Only explicitly configured destinations may be invoked with a run token. Factorize checks the permission, active source run, destination enabled state, enabled manual trigger, and queue capacity at invocation time. Reuse the same `idempotencyKey` when retrying an uncertain request. Destination run details expose `invocation.source_job_id` and `invocation.source_run_id`; human and external invocations leave these values null.
