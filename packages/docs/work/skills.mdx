---
title: Skills
description: Manage reusable team instruction documents independently from Events and Triggers.
---

Skills are standalone Markdown instruction documents with standard `SKILL.md`
frontmatter. They are managed through the browser or `list_skills`, `get_skill`,
`create_skill`, `update_skill`, and `delete_skill` MCP tools. Updates support
revision checks so concurrent edits do not silently overwrite one another.

Creating, editing, or deleting a Skill does not create or modify an Event or
Trigger. Skills do not configure execution settings and are not required to
publish an Event occurrence.
